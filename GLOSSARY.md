# Couchside gathering terms

**Resource type**:
A kind of harvestable herb or mineral. Different node names can represent the same type, such as an ordinary silver vein and an ooze-covered silver vein.

**Resource candidate**:
A tooltip name that matches a catalog entry. The match does not prove the identity of the native object.
_Avoid_: Confirmed resource

**Reference band**:
The Classic skill thresholds (minimum, yellow, green, gray) for a resource type. The difficulty line compares current skill to these bands. It is an estimate, not an exact skill-up chance.
