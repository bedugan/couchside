Stationary scanning

Less manual effort, but a bigger change to runtime behavior. Each scan performs about 1,000 point queries and changes native cursor mode.

Not suitable for the current experimental scanner: its previous soft-cursor state cannot be read and restored. Automatic scanning needs separate input, lifecycle and performance validation.

Recommended closeout: use the macro for the existing herb snapshot prototype, finish outdoor and dungeon display/control checks, and retain keybind/automatic concepts as future work. Macro name/icon and controller button are chosen in WoW by the player.
