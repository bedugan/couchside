Throwaway prototype for Couchside's own settings window, which replaces Blizzard's settings pages (closing those breaks the controller). Mock data. Every control here is one the panel probe confirmed works with the controller: checkboxes, value buttons that cycle, sliders, D-pad tab buttons. No dropdowns, no LB/RB.

Try it like a controller: arrow keys move the highlight (left/right also change a value or slider), Enter is A, Escape is B. Mouse clicks work too. Switch layouts with the bar at the bottom or the [ and ] keys.
