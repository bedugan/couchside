Scan map by controller or while stationary

Gathering 0.13.0 is ready for native testing. It adds a map-icon macro helper and optional automatic scans to the nearby herb list. Automatic mode defaults to off. The wait defaults to one second and accepts whole seconds from 1 to 4.

113 local cases passed, including interrupted scans, manual ownership, macro collisions, errors and the dungeon fallback. Brian's native tests are still required for the new macro API path, repeated cursor changes and later controller input. This candidate is uncommitted.

Create the controller macro

/reload
/cs gathering macro probe

Check the read-only report. If it says ready, the APIs are available, account slots are free and there is no name conflict. If it says exists, the existing Scan map macro is preserved. Creation will not overwrite another macro or assign a controller slot.

/cs gathering macro create

The helper creates Scan map with a native map icon and /cs gathering scan as its body. Use the native macro editor to assign it to your chosen controller action slot. Activate it while still, outside combat, with a visible herb pin and the real cursor outside the minimap. Compare the list and symbols with normal hover. Check movement, Jump, interaction, quest details and the world map afterward. A successful macro call alone does not establish those later controls.

Try automatic scans

/cs option gathering.nearbyList on
/cs option gathering.resourceLegend on
/cs option gathering.autoScan on
  1. With the real cursor outside the minimap, stop moving and turning. The scanner begins after the one-second quiet interval; the sweep takes additional time. Compare the resulting list and symbols with the visible pins.
  2. Remain still for a few refreshes. Automatic requests start no more than once every ten seconds. Routine scans should not flood chat. Each snapshot still expires after ten seconds. Opening a known native panel, such as the world map or quest dialogue, should pause launches and cancel an active automatic sweep; closing it starts a fresh wait.
  3. Walk and turn, then stop again. Movement clears the old display and resets the wait. Starting motion during a sweep should discard its partial result. The minimum interval can delay a later request even after the stillness wait has passed.
  4. Run a scan from the controller macro while automatic mode is enabled. The manual request should replace an active automatic request without overlap. /cs gathering scan off should pause automatic mode until you resume it.
  5. Check normal hover, movement, Jump and interaction. While automatic mode is enabled, open quest details and open/close the world map using the controller. Confirm scans wait while the native panel is open, then check controls again. Repeat these checks after the final reload.

Change the wait

/cs gathering auto delay 3
/cs gathering auto

This example saves a three-second stationary wait. Use 1, 2, 3 or 4; values outside that range are refused. Movement or turning starts a fresh quiet interval. The wait preference survives reload and does not change sweep duration or the ten-second minimum request interval.

Pause or turn it off

/cs gathering auto pause
/cs gathering auto resume
/cs option gathering.autoScan off

Pause and resume affect this session. Turning the option off persists. Manual probes and macro setup also pause automatic mode. Disabling nearby tracking stops automatic polling and cancels its active job.

If hover or controls become abnormal, stop testing and reload. Native query or cleanup failures and protected-action notifications halt automatic requests for the session; resume does not override a fault. If combat or a protected-action notification interrupts a native cursor call, cleanup remains pending. The addon will not call the cursor setter in combat. Reload, or request /cs gathering scan off outside combat, then check controls. The prior cursor state remains unreadable.

Dungeon follow-up

In a safe north-up party instance with a visible herb pin, repeat the stationary scan and compare alignment, movement/turning clearing and expiry. Run /cs gathering display to identify the selected guard. The alternative guard still needs direct native display acceptance. Rotating dungeon minimaps and other instance types remain withheld.

The reload writes scan history and the latest macro/automatic state report. It never restores an old live snapshot or unfinished job. If the automatic option is enabled, a new session starts a fresh wait. Report whether the map icon appeared, the controller macro worked, automatic names/pins matched, changing the wait worked, and all controls continued working before and after reload.

Maintainer handoff and source

MinimapProbe owns all scan jobs and cancellation generations. AutomaticScan owns only launch timing and session pause/fault state. MotionGuard keeps evidence selection private and provides event-aware stationary tokens for automatic launch. No binding override, native panel mutation or controller-page setter is added.

A read-only current-session macro probe gates the explicit creation command. Source inspection establishes the native API call shapes, not addon-side taint safety. The macro report retains observed metadata and client/build. Creation is checked by re-reading the saved macro and never automatically retried.

The launch suite adds 43 cases to the existing checks. A failed-cleanup regression caught a stale completed-job watchdog retry; completed automatic jobs now stop after that failure.
